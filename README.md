## Pothole Detection and Severity Grading :)

### Steps to replicate Code
- Clone the repository.
```
git clone https://github.com/NoramiraHusna/Deeplearning-
```

- Install requirements with the mentioned command below. (check modified req.txt file)
```
pip install -r requirements.txt
```
- GPU users only (CPU users ignore)
```
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
```
- Run the code with the mentioned command below.
 
 >test
`python test.py`

> training using dataset
`python im.py > python train.py`

> model comparison
`python comp.py `
